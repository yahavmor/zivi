# מושעה מהמשחק — Metal Version

גרסת מטאל מודרני וכבד של אותו משפט: **"אתה מושעה מהמשחק, אתה מושעה, אתה מושעה מהמשחק!"**

## הקונספט

110 BPM, דו מינור, גיטרות ב-Drop C (מיתר נמוך C2 = 65 Hz). ההברה הצועקת "מֵ" של "מֵהמשחק" נוחתת על דאונביטים של ריף A, הבילד, ה-Breakdown (קול שד), הקליימקס והסיום.
ההומור: משפט יומיומי שמקבל טיפול של המנון מטאל: תזמורת, מקהלה, Double Kick, Breakdown עם קול באוקטבה למטה, ומשרוקית... לא, הפעם בלי משרוקית.

## איך זה נבנה

אין כאן סאמפלים מוקלטים של גיטרה או תופים: הגיטרות הן מודל מיתר פיזיקלי (Karplus-Strong/waveguide) דרך סימולציית מגבר (שלושה שלבי דיסטורשן אסימטריים ב-4x oversampling, Tone stack, IR סינתטי של ארון 4x12) בשני טייקים עצמאיים ימין/שמאל; הבס הוא מיתר מסונתז עם פיצול לתת-תחום נקי ואמצע מעוות; התופים הם שכבות סינתזה (קיק, סנר) על סאמפלים של הסאונדפונט FluidR3 (מצלתיים, טומים); התזמורת והמקהלה דרך FluidSynth; הקול מההקלטה המקורית דרך Rubber Band (שינוי גובה עם שימור פורמנטים) ושרשרת אפקטים.
העיבוד עצמו (ריפים, תופים, ליד) נכתב כנתונים ב-`riffs.json`: שלושה "מלחינים" עצמאיים הציעו עיבודים ושופט בחר והרכיב.

## הרצה מחדש

```
apt-get install ffmpeg fluidsynth fluid-soundfont-gm rubberband-cli

cd metal
python3 metal_song.py main          # או: instrumental  (כ-4 דקות)
python3 export_metal.py <תיקיית יעד>
```
