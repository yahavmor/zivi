# מושעה מהמשחק — Late Night R&B Edit

רמיקס R&B לילי שנבנה סביב ההקלטה המקורית:
**"אתה מושעה מהמשחק, אתה מושעה, אתה מושעה מהמשחק!"**

## הקונספט

72 BPM, סול מינור. הקול יושב באופן טבעי סביב Bb3 ונופל ל-G3 בסוף המשפט, ולכן הסולם נבחר סביבו.
ההומור מגיע מהפער: הפקה לילית, אינטימית ומושקעת סביב משפט של שופט שמשעה מישהו מהמשחק.
ה"מֵ" הצועק של "מֵהמשחק" האחרון הוא הכי חזק בהקלטה (20 dB מעל השאר) והוא נקודת ה-Drop של הקטע.

## איך להריץ מחדש

```
cd production

apt-get install ffmpeg fluidsynth fluid-soundfont-gm rubberband-cli
python3 vocal.py          # ניקוי ההקלטה וחיתוך למילים
python3 song.py main      # או: instrumental / extra
```
